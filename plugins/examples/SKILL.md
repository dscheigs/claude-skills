# Example Skill

This is an example skill that demonstrates how to structure skills for the marketplace.

## Usage

When invoked with `/example-skill`, this skill provides guidance on creating new skills.

## Instructions

When the user invokes this skill:

1. Explain that skills are defined using SKILL.md files with YAML frontmatter
2. Show the basic structure of a skill
3. Provide examples of what skills can do
4. Help the user create their own custom skill if requested

Skills can contain specialized instructions, reference documentation, templates, and more. They extend Claude's capabilities by providing domain-specific knowledge and workflows.
